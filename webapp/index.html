操作说明

  1. 加密：直接敲键盘（或用鼠标点击键盘），灯盘亮起的字母即为密文；电报纸带会记录「明文 › 密文」。
  2. 调节齿轮：点击齿轮旁的 ▲▼ 或在齿轮盘上滚动滚轮；机器每次加密前会像真机一样自动步进。
  3. 更换齿轮：点击齿轮盘打开齿轮仓库，可装入 I–VIII、Beta、Gamma，也可编辑、新建自定义齿轮——自定义接线、转换点，甚至自定义字母表（例如「甲乙丙丁」）。
  4. 插线板：先点一个插座，再点另一个即可接上电线；点击电线或已连接的插座可拔下。最多 10 根（与真机相同）。
  5. 反射板：点击左上角的反射板窗口，可更换 B / C / B-thin / C-thin 或新建反射板。
  6. 解密：恩尼格玛是自反的——把所有齿轮调回加密时的初始位置，重新敲入密文，灯盘就会亮出明文。
  7. 粘贴即输入：在页面上直接粘贴文本，会自动忽略字母表以外的字符，并以匀速逐字加密演示（按 Esc 可中途停止）。
  8. 键盘布局：顶部「设置」对话框里可切换 QWERTZ / QWERTY / AZERTY / Dvorak / A–Z 顺序（仅 26 个拉丁字母生效；排布与真实键盘一致，9/8/9 三行；物理键盘输入不受影响）。手机上按键会自动放大并填满整行宽度。
  9. 机械设置：顶部「设置」对话框中的「反向轮转 rotate_up」与「后步进 rotate_after_type」对应库的 Enigma 构造参数；复现 README 的微型中文机示例（甲乙丙丁）时需同时打开。
  10. 自定义字母表：齿轮与反射板可以随意创建、替换，但整机要求二者字母表一致——安装齐全后键盘/灯盘/插线板才会启用（未齐时机器上方会有提示）。字母表不是 26 个拉丁字母时，它们会换成通用字符面板：点击字符、在输入框输入后点「发送」或回车。

所有运算都由 myenigma 在浏览器内的 WASM Python（Pyodide）中完成：没有后端服务器。齿轮仓库与配置保存在浏览器本地。
